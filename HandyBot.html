Idea & real‑world problem

Inspired by Ron's Gone Wrong — teachers and admins deserve a real‑life “B‑Bot” to lend a physical hand.

📋 60% of admins
📄 15% lost time

Manual handling causes fatigue, dropped documents, and lost confidentiality. HandyBot secures stacks automatically.

👩‍🏫 K‑12 teachers
🏢 office assistants

Target users: school staff, professors, and multi‑tasking professionals like “مدام عفاف”.

Solution & interaction

HandyBot is a sensor‑activated robotic arm (5‑DOF) that detects approaching stacks of files (HC‑SR04 ultrasonic) and clamps them securely using servo motors.

1 Approach & detect < 10cm
2 Automatic clamping
3 LED green + chime
4 Release via button / web
Proximity auto‑grip 5‑DOF stability Smart safety alerts IoT web override

System architecture

[ INPUT LAYER ] |-- HC-SR04 Sensor (Ultrasonic Distance) | v [ PROCESSING LAYER ] |-- ESP32 / Arduino (Dual-Core Brain) | v [ OUTPUT LAYER ] |-- 5x SG90 Servo Motors (5-DOF Arm) |-- Status LED & Buzzer (Feedback) | v [ CONNECTIVITY LAYER ] |-- Wi-Fi Router / Web Dashboard App

Continuous loop: input → processing → output → connectivity. Distance processed every 100ms.
